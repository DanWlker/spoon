Spoon keymap

Every default key, grouped by where it works. A blue key starts a sequence: press it, a popup lists the keys finishing it there, then press one. A key of an inner part overrides the same key around it, like y copying the selected lines at once in a diff. Actions with no key run from the keys list (?), which also lists every action of the focused panel. See Keybindings for the details and Custom Keybindings to change them.
