# FAQ

## Why doesn't the graph display?

Spoon displays the commit graph using specific terminal graphics protocols (such as Kitty and iTerm2 inline images).

**If your terminal emulator doesn't support one of these protocols, Spoon will not work — there is no fallback or workaround.**

This is a fundamental requirement, not a limitation that can be worked around.
For a list of supported terminal emulators and compatible environments, see [Compatibility](../getting-started/compatibility.md).
